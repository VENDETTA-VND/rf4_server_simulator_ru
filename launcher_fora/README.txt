RF4 — ЛАУНЧЕР ДЛЯ ДРУЗЕЙ
========================

Это отдельный клиентский лаунчер. Он НЕ запускает Docker, gateway, gameserver,
базу данных или административную панель. Друзьям нужен только установленный RF4.

ПЕРЕД РАЗДАЧЕЙ ДРУЗЬЯМ
1. Откройте config.json.
2. Замените ВПИШИ_СВОЙ_ВНЕШНИЙ_IP на ваш реальный внешний IPv4.
   Пример формата: 203.0.113.10 (это пример, не используйте его как свой адрес).
3. Сохраните файл и отправьте друзьям всю папку «Лаунчер для друзей».

КАК ПОЛЬЗОВАТЬСЯ
1. Запустите «Запустить лаунчер.bat». Windows запросит права администратора:
   они нужны только для изменения системного hosts.
2. Один раз укажите путь к rf4_x64.exe кнопкой «Обзор…».
3. «Играть на моём сервере» добавляет в hosts записи:
   ВАШ_IP api.rf4game.ru
   ВАШ_IP api.rf4game.com
4. «Обычная / официальная игра» удаляет только строки, помеченные этим лаунчером.
5. В блоке «Аккаунт» введите логин и пароль; кнопка «Регистрация» создаёт новый аккаунт,
   а «Войти в аккаунт» авторизует существующий. После успеха лаунчер сохраняет игровой
   login_token в %APPDATA%\RussianFishingLLC\RussianFishing4\Session.dat.
6. Нажмите «ЗАПУСТИТЬ ИГРУ» после выбора нужного режима.

ТРЕБОВАНИЯ ДЛЯ АККАУНТОВ
- На сервере должна быть версия с миграцией 00073_player_account.sql.
- HTTPS-адрес api.rf4game.ru должен вести на ваш сервер, а TLS-сертификат должен быть
  действительным и доверенным Windows на компьютере каждого игрока.
- Регистрация и вход доступны через HTTPS POST /account/register и /account/login.
- Логин: 3–32 символа A-Z, a-z, 0-9, подчёркивание или дефис. Пароль: 8–128 символов.
- Не раздавайте одну учётную запись нескольким игрокам: у каждого должен быть свой UID.

БЕЗОПАСНОСТЬ
- При смене режима лаунчер удаляет только две свои точные строки (IP + api.rf4game.ru/com + маркер # rf4-friend-launcher).
- Все остальные записи и комментарии в hosts сохраняются; исходная кодировка и тип переводов строк сохраняются.
- IP и путь к игре сохраняются в config.json.
- Если лаунчер не может записать hosts, проверьте, что он запущен с правами администратора.

ТРЕБОВАНИЯ К ВАШЕМУ СЕРВЕРУ
- На серверной машине gateway должен рекламировать внешний IP/DNS в gateway.advertise_host.
- Должны быть доступны извне TCP 443 и TCP 9341 (проброс портов на роутере и правило Windows Firewall).
- При CGNAT обычный проброс портов не сработает; потребуется публичный IP или VPN-сеть
  (например, Tailscale/ZeroTier), и тогда в лаунчере указывается адрес этой VPN-сети.
